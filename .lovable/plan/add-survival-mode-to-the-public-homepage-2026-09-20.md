# Add Survival Mode to the public homepage

## Goal
Make the existing Survival Mode discoverable from the public homepage and visually distinguish it from the regular planning experience.

## Homepage addition
- Add a full-width Survival Mode section after the main product explanation and before the FAQ.
- Present it as the calm alternative for difficult or overloaded days: mind stability, body readiness, sustainable work, and practical preparedness.
- Keep the message concise and explicitly separate from goals, ranks, streaks, and AI.
- Include a prominent button linking directly to `/survival` and a secondary path back to the regular workspace where appropriate.

## Visual direction
- Use the selected **subtle dark band**: the Survival section itself changes to a charcoal monochrome theme while the rest of the homepage remains light.
- Ease the background, text, borders, and supporting garden details into the dark section as it enters the viewport, without changing the user's saved app theme.
- Continue the existing living-garden language with restrained silhouettes or butterfly movement adapted for the darker band.
- Respect reduced-motion settings by showing the final dark styling without scroll animation.

## Public navigation
- Add a clear Survival Mode link to the public site navigation and mobile menu so visitors do not need to discover it only by scrolling.
- Add the same destination to the public footer for consistent access.

## Validation
- Verify the homepage section and both navigation links open `/survival`.
- Check the dark band at mobile and desktop sizes, including readable contrast and no overlapping garden elements.
- Confirm scrolling does not alter the saved app theme or make other public pages dark.
- Confirm the homepage still loads without stuck image placeholders and the preview remains error-free.
